## What is NOT covered by the Brand reservation

- The **code** itself. You may use, modify, and distribute the code
  under LICENSE / LICENSE-APACHE / commercial license.
- **Plain-text factual references** to the project's name in
  academic papers, books, articles, reviews, tutorials, bug reports,
  presentations, and conference talks. The key requirement is that
  the reference does not suggest endorsement, sponsorship, or
  affiliation.
- **Public discussion** of the project in forums, chat groups, and
  social media.
- **Functionality names** that describe what the software does
  (e.g. "local AI assistant", "file indexer"). These are descriptive
  terms and may be used by anyone.


## Permitted uses WITHOUT separate permission

You MAY, without separate permission, do the following, provided
your use is not Commercial Use of the Brand itself (in which case
see the commercial Brand license below):

1. Use the unmodified name of the project in descriptive text about
   the project (e.g. "Built on OI Enhancements" or "Compatible with
   Prisir AI v2.6") — provided the use is factual, does not suggest
   endorsement, and is not the name of your own competing product.
2. Distribute the unmodified Software under its original Brand
   elements (name, icon, logo) for Personal Non-Commercial Use, in
   compliance with LICENSE.
3. Reference the project name in package metadata (e.g. PyPI,
   crates.io) where the package is the actual unmodified
   OI Enhancements project, and where the use does not suggest
   endorsement of a derivative product.
4. Use the project name in a fork name or derivative work name
   ONLY if the fork or derivative is clearly identified as such
   (e.g. "Prisir AI — Community Tools Extension") and does not
   mislead users into believing it is the official project.

## Prohibited uses WITHOUT separate permission

You MAY NOT, without a separate written permission or commercial
trademark license, do the following:

1. Use any reserved Brand element as the **name or logo** of a
   product, service, derivative work, fork, or fork-and-rebrand
   project that is the official-sounding name (e.g. naming your
   product "Prisir AI Pro" or "Prisir-AI-Cloud").
2. Use any reserved Brand element on a product, web site, or
   packaging that **suggests endorsement, sponsorship, or
   affiliation** by the Project Copyright Holder, when no such
   relationship exists.
3. Register or use a domain name, social media handle, app store
   listing, or GitHub organization that contains a reserved
   Brand element in a way that suggests ownership or official
   status.
4. Use any reserved Brand element in advertising, marketing, or
   promotion of Commercial Use that is not covered by a commercial
   license.
5. Modify the Brand logo or icon and present the modified version
   as if it were the original Brand.

A commercial **code** license (LICENSE §4) does NOT grant rights to
the Brand. They are separate grants.


## What happens if I fork and rename?

You MAY fork the code and develop a derivative work under LICENSE
(or LICENSE-APACHE for a Legacy Community Release). When you
**Distribute** the derivative work:

- You MAY choose your own name for the derivative work. You MAY NOT
  use any reserved Brand element as the name of your derivative
  unless you have a separate Brand license.
- You MAY use the unmodified name of this project to **identify the
  source** of the code (e.g. "Forked from Prisir AI v2.6,
  copyright 63894696, used under OIE-PCS-1.0").
- You MUST NOT use the Brand icons/logos in your derivative work
  unless you have a separate Brand license, even if you replace
  them with very similar marks.


## Fork branding guidance

A derivative work whose upstream is OI Enhancements is encouraged
to:

- adopt a clearly different name (e.g. "Prisir-Community-Edition",
  "Prisir-AI-Fork-XYZ");
- include the upstream version, OIE-PCS-1.0 (or LICENSE-APACHE for
  legacy releases), and the copyright notice of the upstream;
- include a NOTICE OF MODIFICATION listing the modified files;
- ship with its own icon and logo, not the upstream's.
