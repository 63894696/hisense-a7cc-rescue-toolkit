## 🔑 关键技术点

### 1. 进 autodload 模式的按键

```
音量上 + 音量下 + 电源 (三个键,10-15 秒)
```

注意:**不是 音量上+音量下+电源**,而是**电源+音量上**(spd_dump 自己的提示)用于重启。

### 2. 驱动必须是 WinUSB

| 驱动协议 | 支持 spd_dump | 备注 |
|---|---|---|
| WinUSB | ✅ | **推荐,就是 Zadig 默认装的** |
| libusbK | ❌ | 会拦截 spd_dump |
| libusb-win32 | ❌ | 不兼容 |
| Spreadtrum 原厂 | ❌ | SciU2S 驱动,只支持官方工具 |

### 3. WSL 必需,不是可选

```
4bitFox 自己说: "I didn't manage to make the program recognize my phone in Windows"
```

spd_dump.exe 在 Windows 下找不到设备是已知问题。**必须用 WSL**。

### 4. usbipd-win 是把 USB 转发给 WSL 的工具

```
bind --busid 1-10     ← 让 usbipd 接管 USB 设备
attach --busid 1-10 --wsl   ← 转发给 WSL
```

**必须先保持 WSL 在运行**(不然 attach 会失败):
```bash
wsl -d Ubuntu-24.04 -- bash -c "sleep 1000"
```

### 5. spd_dump 命令的执行顺序

**完整救砖 = 4 段命令**:

#### 第 1 段:备份原厂安全分区(必须先跑)
```bash
./spd_dump skip_confirm 1 fdl fdl1-dl.bin 0x5500 fdl uboot-mod.bin 0x9efffe00 \
  exec read_part splloader 0 1m spl.bin \
       read_part teecfg 0 1M teecfg.bin \
       read_part trustos 0 6M tos.bin \
       read_part sml 0 1M sml.bin \
       erase_part splloader erase_part splloader_bak reset
```

**关键点**:
- `skip_confirm 1` — 跳过 `Answer "yes" to confirm` 的确认(WSL 下没 stdin)
- 这步会生成 spl.bin/teecfg.bin/tos.bin/sml.bin — **必须保留!** 是恢复的最后保障
- `erase_part splloader` — 擦掉 SPL,手机进入半砖状态

#### 第 2 段:写回安全分区
```bash
./spd_dump fdl fdl1-dl.bin 0x5500 fdl uboot-mod.bin 0x9efffe00 \
  fdl teecfg.bin 0x9401fe00 \
  fdl tos.bin 0x9403fe00 \
  fdl sml.bin 0x93fffe00 \
  exec skip_confirm 1
```

#### 第 3 段:检查 unlock 状态(可选)
```bash
./spd_dump fdl fdl1-dl.bin 0x5500 fdl uboot-mod.bin 0x9efffe00 \
  exec verbose 2 read_part miscdata 8192 64 m.bin reset
```

#### 第 4 段:写签名 SPL + 清 userdata(救活)
```bash
./spd_dump fdl fdl1-dl.bin 0x5500 fdl uboot-mod.bin 0x9efffe00 \
  exec skip_confirm 1 erase_part uboot_log \
       write_part splloader u-boot-spl-16k-sign.bin \
       timeout 100000 \
       write_part userdata userdata.bin reset
```

**关键点**:
- `u-boot-spl-16k-sign.bin` 是签名版 SPL,绕开签名验证
- `timeout 100000` — 100 秒超时,写入较慢
- `userdata.bin` — 清空用户数据(相当于恢复出厂)

## ⚠️ 救砖过程中的关键警示

### 1. 手机在擦 SPL 后,千万不要断电

```
擦除 SPL 后,手机处于"半砖"状态
如果此时断电/USB 断开,手机将无法启动,只能短接主板进 9008
```

**正确做法**:擦 SPL 后立刻跑第 4 段写新 SPL,不要等。

### 2. spd_dump 的"按电源+音量上 7-10 秒"提示

```
wrong command or wrong mode detected, 
reboot your phone by pressing POWER and VOL_UP for 7-10 seconds.
```

当手机在 splloader 缺失状态下,spd_dump 会提示这个。意思是:
- 按 电源+音量上 让手机从 splloader 缺失状态**触发内部 reset**
- 然后 spd_dump 就能继续通信

**不是 autodload 按键组合**(音量上+下+电源)。

### 3. usbipd attach 会"断"

attach 后,如果:
- WSL 退出
- spd_dump 跑完一段后 USB 状态变化

都会让 attach 断开。**每次跑 spd_dump 前都要确认 attach 状态**:
```bash
"/c/Program Files/usbipd-win/usbipd.exe" list | grep iWHALE
```

如果是 `Shared` 而不是 `Attached`,要重新 attach。

### 4. spd_dump 的 verbose 参数

- `verbose 0` — 默认,最少输出
- `verbose 1` — 基本输出
- `verbose 2` — 完整输出(救砖建议用这个)

```
1. 按 音量上+音量下+电源 进 autodload
```

1. usbipd 是否 attach 成功
2. WSL 是否在运行
3. /sys/bus/usb/devices/1-1 是否存在
4. 按 电源+音量上 是否触发 reset

## 🛡️ 防再变砖建议

### 立即做

1. **备份手机数据**
   ```
   adb pull /sdcard D:\hisense-backup\
   ```

2. **备份当前 SPL**
   ```
   adb shell su -c "dd if=/dev/block/by-name/splloader of=/sdcard/splloader-backup.img"
   adb pull /sdcard/splloader-backup.img C:\...
   ```

3. **备份 boot/recovery 分区**
   ```
   adb shell su -c "dd if=/dev/block/by-name/boot of=/sdcard/boot-backup.img"
   adb shell su -c "dd if=/dev/block/by-name/recovery of=/sdcard/recovery-backup.img"
   adb pull /sdcard/*-backup.img C:\...
   ```

### 长期做

1. **不要随便刷第三方 ROM** — 海信 A7 墨水屏机型对系统兼容敏感
2. **升级前先备份** — 任何系统更新前,用 ADB 备份关键分区
3. **保持 SPL 备份** — 把 spl.bin/teecfg.bin/tos.bin/sml.bin 存到云盘
