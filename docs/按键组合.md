# 海信 A7 CC (HNR320T) 按键组合

## 救砖必备按键

| 模式 | 按键组合 | 用途 |
|---|---|---|
| **autodload / Download 模式** | `音量上 + 音量下 + 电源` 10-15 秒 | 救砖必用,手机进 Download 模式 |
| **spd_dump 重启** | `电源 + 音量上` 7-10 秒 | spd_dump 提示时按,触发内部 reset |
| Recovery (TF 卡升级) | `E-Ink 键 + 音量上 + 电源` | 有 TF 卡槽时用 |
| Recovery (擦 userdata) | `E-Ink 键 + 音量下 + 电源` | 危险!擦用户数据 |
| Bootloader | `adb reboot bootloader` | 需 ADB 通 |

## 关键区分

- **autodload 模式** = 音量上+音量下+电源(3 键)
- **spd_dump 重启** = 电源+音量上(2 键,不是 autodload 组合)

**最容易搞错**:很多人按音量上+音量下+电源进 autodload 后,spd_dump 提示"wrong command or wrong mode"时,又按 autodload 组合,结果完全无效。**正确是按电源+音量上 7-10 秒**。
