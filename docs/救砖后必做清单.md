## 🚨 关键警告

### 1. 预装应用里的潜在风险

备份的 39 个 APK 里,有几个**可疑**:
- `FansClub` — 海信粉丝俱乐部(可能有推送)
- `GoodFather` — 名字可疑(可能是推广渠道)
- `NewsArticle` / `TencentNews` — 资讯推送(可能有广告)

**这些应用可能**:
- 上报设备信息到第三方
- 在后台静默下载广告
- 占用电池和流量

**但要确认需要**:
- 拆 APK 看 lib/ 里的 .so
- 网络抓包看上报行为
- **这是下个窗口的工作**

### 2. "另一台设备已发生恶意监控现象"

你提到的这句话**非常重要**,需要在新窗口深度讨论:
- 恶意监控是怎么发现的?
- 具体表现是什么(后台录音/摄像头/位置上报)?
- 用的什么设备?
- 是否已经装了 ROOT 工具发现?

**这些信息影响隐私保护方案的设计。**

### 3. ROOT 海信 A7 的风险

如果你决定 ROOT:
- **解锁 bootloader 会清空所有数据**
- **需要 Magisk + 已签名的 boot.img**
- **如果打错补丁,手机会再次变砖**
- **变砖后救砖流程要再走一遍**(但有了救砖工具,半小时能救活)

**强烈建议新窗口深度讨论,不要现在做。**
